# Glossary

The words the product uses, what they mean, and which ones are the game's rather
than ours.

**The build is the authority.** If a label exists on screen, quote it exactly —
**Rest of Town**, **From save**, **Died of**, **Moving out**, **Back to Auto**.
Don't paraphrase one and don't invent a synonym for a word the app already uses
everywhere.

---

## 1 · The game's words, used unchanged

These are The Sims 4's own terms. We use them as the game does, and getting one
subtly wrong is the fastest way to lose a Sims player's trust.

| Term | Notes |
|---|---|
| **Sim** · **household** · **lot** · **world** · **neighbourhood** | A household lives on a lot; a lot sits in a neighbourhood; neighbourhoods make a world |
| **Lot type** | What a lot *is* — Residential, Bar, Vet Clinic, Small Business Venue. Changing it is *retyping* |
| **Venue** | A non-residential lot. Also, with **Custom Venue**, a specific lot type of its own |
| **Lifestage** | Newborn · Infant · Toddler · Child · Teen · Young Adult · Adult · Elder. Never "age group" |
| **Trait** · **aspiration** · **skill** · **career** | Personality, life goal, learned ability, job |
| **Occult** | Vampire, Alien, Mermaid, Spellcaster, Werewolf, Fairy — and **Ghost**, which the planner lists alongside them |
| **Simoleons (§)** | Household funds |
| **Pack** | An Expansion, Game or Stuff Pack. Referred to by name — *Get Together* — with the code (EP02) only where the code is on screen |
| **Club** | Get Together. Has a **leader**, **members**, **requirements**, **encouraged / discouraged activities** and a **hangout** |
| **Holiday** | Seasons. Has **traditions**, a **decoration theme**, and a day off work & school. **Season length** is 7, 14 or 28 days |
| **Small business** | Businesses & Hobbies. Has an **owner**, **employees**, **customer requirements**, **activities**, a **fee**, **renown** and **alignment** |
| **Custom venue** | Adventure Awaits. Has **roles** and **time slots**; a **getaway** is the hosted kind |
| **Dynasty** | Royalty & Legacy. Roles are **Head · Heir · Founder · Black Sheep · Member**; it has **ideals**, **prestige** and **unity** |
| **Gallery** | The in-game Gallery. A **Gallery ID** is a search handle you type in-game — never a link |

## 2 · Our words for our own ideas

Nothing here is a Sims term. Each one names something the planner invented, and
each has a wrong version people reach for.

| Our word | What it means | Not |
|---|---|---|
| **Plan** | Everything in the app. A *future* save you're working towards | Not a mod, not a save editor |
| **Save file** (in the app) | One plan. The container for worlds, lots, households, photos | Not the `.save` — see §4 |
| **Sync** / **re-sync** | Pulling your `.save`'s current state back into the plan | Not two-way, not "upload" |
| **Link** | Attaching a `.save` file to a plan for the first time | Not import — import *creates* a plan |
| **My Households** / **Rest of Town** | The two zones the household list splits into: the families you care about, and everyone else | |
| **Yours · Premade · Townie · Service Sim · Mod · Plan-only** | The six provenance badges saying where a household came from | |
| **From save** / **PLANNER** | The two origins a record can have. Save-backed records are read-only; the plum **PLANNER** pill marks ones you made | |
| **Unplanned · Planned · Built** | A lot's build status. Yours entirely — the game never sets it | Not occupancy: a lot with a family living on it still reads Unplanned until you touch it |
| **Funds target** | A figure you're planning a household to reach | Not their balance |
| **Planned move** · **planned skill** · **planned career** | Goals you author on a sim | Not what they have now |
| **Inspo** | The reference-image side of the app | Not showcase — see §3 |
| **Pool** | Your whole inspo library. One per account, shared by every save | Not per-save |
| **Board** | One world's moodboard, built from photos filed to it | |
| **Filing** / **assign** | Putting a photo on a world or a lot. It's a tag, so nothing leaves the pool | Not moving, not uploading |
| **Tag** | The only metadata an inspo photo carries. Your own vocabulary | Not a caption — inspo photos have none |
| **Showcase** | The public, shareable face of a save | |
| **Tree-only · culled · stub** | Sims kept for the family tree but off the roster: the save still has them, the save dropped them, or the game only names them | |
| **Unknown** | An ancestor the game references but no longer stores. Shown as a dashed card you can name | |
| **Preserved — no longer in the save** | A sim the game culled that the plan is keeping | |
| **`.s4plan`** | The backup file a plan exports to. A zip of the plan plus its images | Not a `.save` |
| **Deleted & backups** | The trash. Deleted saves last 30 days, automatic backups 7 | |
| **Auto-backup** | The full copy taken before every sync and every reset | |
| **Auto · On · Off** | The three states of a pack switch. Auto follows what your saves showed | |
| **Locked** | A pack you're not treated as owning. Soft — nothing is blocked | |
| **Disabled** | A world you switched off for one save | Not locked — different reason, different colour, different scope |
| **Hidden** | A photo or a mod kept out of one save without deleting it | |

## 3 · Pairs that get mixed up

These are the ones to check every time. Each pair reads as interchangeable and
isn't.

**Notes vs Description.** **Notes are private, everywhere, on everything.**
**Descriptions are public** — they appear on a shared showcase. Both exist on
lots, households and most managers.

**Inspo photo vs Showcase photo.** Inspo is reference you gathered — private,
tagged, filed to worlds and lots, one account-wide pool. Showcase photos are
finished builds — captioned, credited to a gallery creator, and **public**. A
lot's first showcase photo becomes its cover and moves it to **Built**.

**Head vs Leader.** A **dynasty** has a **Head**. A **club** has a **Leader**.
Never swap them.

**Three different resets.**

| Control | Where | What it does |
|---|---|---|
| **Reset lot** | Lot editor | *Factory* reset: back to what the lot shipped with **in the game** — not to your save. Clears status, notes, description; moves residents out |
| **Reset planner data** | Save settings | Wipes everything you've planned in one save, keeps the save, its link, its settings and its photos |
| **Start over** | Pack ownership | Turns every pack on and forgets what your saves detected |

**Three different greys.** **Locked** = a pack you don't own. **Disabled** = a
world you switched off for this save. **Hidden** = a photo or mod you kept out of
this save. They look similar and mean nothing like each other.

**Import vs Sync vs Restore.** **Import** reads a `.save` and creates a new plan.
**Sync** updates an existing plan from a `.save`. **Restore** brings a plan back
from a `.s4plan` file or the trash — no `.save` involved.

**Remove vs Delete.** On a record that came from your save, **Remove** takes it
out of the plan and the next sync brings it back — so it behaves as *hide until
next sync*, and the notes you wrote don't survive the round trip. Only a record
you created here is gone for good. On **Mods**, **Delete** is account-wide while
**Hide from this save** is the per-save one.

**Assign.** The verb for attaching anything to anything — a household to a lot, a
photo to a world, a lot to a business. Don't coin a synonym.

## 4 · `.save` vs save file

The one genuinely ambiguous word in the product, worth spelling out.

- **Your `.save`** is the game's file, on your computer, in
  `Documents/Electronic Arts/The Sims 4/saves`. We read it and never write to it.
- **A save file** in the app is your plan. It's what `/saves` lists, what you
  open, rename, duplicate and share.

They are linked but not the same, and one plan can be re-pointed at a different
`.save` — which is exactly what happens after an in-game **Save As**.

## 5 · Words we don't use

- **CAS.** That's the game's own creator. Ours is the **creation modal** or the
  **sim builder**.
- **Gallery profile link.** EA publishes no such page; a Gallery ID is a search
  handle.
- **Caption**, of an inspo photo. They were removed; tags replaced them. Showcase
  photos still have captions.
- **Save editor**, **injector**, **mod**, **cheat**. None describe this product.
